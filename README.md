# Tehqeeq | تحقیق

Open source media verification and documentation 
infrastructure for Pakistan.

---

## Why this exists

Every time something happens in Pakistan... AJK, Balochistan, 
an election, a crackdown... the same thing follows. Videos 
everywhere. Nobody can tell what's real. Both sides push 
their version. Confusion wins by default because confusion 
is easy and verification is hard.

But there's a deeper problem underneath that.

When you ask an AI what actually happened in some event, 
the answer is usually "not documented, cannot verify." Not 
because the truth doesn't exist. Because the only people 
who bothered to document it had a reason to. And people 
with a reason to document things have a reason to frame 
them a certain way.

Unbiased people don't document because nobody built them 
the infrastructure to do it easily and safely.

Tehqeeq is that infrastructure.

---

## What we're building

Two things that feed into each other.

**Verification tool**

Paste a link to any video or image circulating in Pakistani 
media. We extract everything technically knowable about 
where it actually came from... metadata, reverse search 
results, source domain patterns, timestamp signals, 
geolocation clues.

We don't give you a verdict. We give you evidence. 
You think for yourself.

**Documentation layer**

A versioned, anonymously contributed, community maintained 
record of Pakistani political events and institutional claims. 
Built specifically so AI systems can actually read it and 
give accurate answers instead of "not documented."

Think Wikipedia meets Reddit meets git history, but built 
for Pakistani context with real anonymity protection and 
a verified/unverified/contested tier system so nothing 
gets flattened into false certainty.

When the verification tool finds something, it feeds into 
the documentation layer. The documentation layer makes 
future verification faster. The loop closes over time.

---

## Why open source and distributed

Because single owner infrastructure can be pressured, 
shut down, or compromised. We've seen it happen.

Tehqeeq is built from day one with no single point of 
failure. Multiple maintainers, mirrored repositories, 
no central server anyone can switch off with a phone call.

The findings belong to everyone. The infrastructure 
belongs to no one.

---

## Who this is for

Anyone who watched a video from AJK or Balochistan and 
had no way to tell if it was real.

Anyone who asked an AI about a Pakistani political event 
and got "not documented" back.

Anyone who thinks the answer to manufactured confusion 
is infrastructure, not just more opinions.

## How to contribute

This is a cross border open source project. Pakistani and 
Indian contributors both welcome... we're dealing with the 
same broken information environment from different sides.

If you're a developer, open an issue and pick something 
to build. If you're a researcher, the documentation layer 
needs people who will write one verified entry about one 
event they witnessed or can source. That alone is enough. 
If you're a designer, the verification tool needs a UI 
that works on mobile in Pakistan. If you're a journalist, 
your methodology input is genuinely valuable.

Join the Discord: https://discord.gg/m4sjuKQzn
Open an issue and tell us what you want to build.

---

## How we work

Tehqeeq doesn't take political sides. It takes the side 
of verifiable evidence. State actors and non-state actors 
are held to the same standard. A fake video is a fake 
video regardless of who benefits from it spreading.

Our verification methodology is public and open to 
challenge. If our process is wrong, tell us why with 
evidence and we'll update it.
