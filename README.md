# Tehqeeq | تحقیق

Open source media verification and documentation 
infrastructure for the Pakistani information environment.

---

## The Problem

When something happens in Pakistan — a protest, a crackdown, 
a political event — the information environment fractures 
immediately. Real videos, fabricated videos, old footage 
relabeled, misattributed images, coordinated fake networks. 
Both state and non-state actors run information operations. 
Ordinary people have no tools to navigate any of it.

The deeper problem: when you ask an AI what actually happened, 
the answer is often "not documented, cannot verify." Not because 
the truth doesn't exist — because unbiased people don't document. 
Only motivated, biased people do. So the documentation itself 
is systematically skewed toward whoever had the strongest reason 
to write it.

Tehqeeq exists to close that gap.

---

## The Solution

Two interconnected tools:

**1. Verification Layer**
Paste a link to any video or image circulating in Pakistani 
media context. Tehqeeq extracts everything technically 
extractable about its origin — metadata, reverse search 
results across multiple engines, source domain analysis, 
upload timestamp inconsistencies, geolocation signals.

Not a verdict. Evidence. You decide.

**2. Documentation Layer**
A versioned, anonymity-protected, community-maintained 
record of Pakistani political events, institutional claims, 
and documented patterns — structured specifically for AI 
readability.

Modeled on Wikipedia's collaborative structure but built 
for Pakistani context with:
- Anonymous contribution (no identity required)
- Verified / Unverified / Contested tiers
- Full edit history — nothing disappears
- Structured data format for AI consumption
- Moderator oversight with transparent decision logs

If our verification tool finds something, it feeds into 
the documentation layer. The documentation layer makes 
AI responses about Pakistani events actually accurate. 
The loop closes.

---

## Why Open Source and Distributed

Because any single-owner infrastructure can be pressured, 
shut down, or compromised. 

Tehqeeq is built from day one to have no single point of 
failure — multiple maintainers, mirrored repositories, 
no central server that can be switched off.

The findings belong to everyone. The infrastructure 
belongs to no one.

## Methodology

Tehqeeq does not take political sides. It takes the side 
of verifiable evidence. State actors and non-state actors 
are held to the same standard. A fake video is a fake 
video regardless of who benefits from it spreading.

Our verification methodology is public and open to 
challenge. If our process is wrong, tell us why with 
evidence. We will update it.
